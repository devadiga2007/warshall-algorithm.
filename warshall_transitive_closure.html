Transitive Closure of a Relation using Warshall’s Algorithm

Learn how to find the transitive closure of a relation using adjacency matrices, the Warshall update rule, worked steps, an interactive matrix explorer, and practice exercises.

01 · Learn

Definitions

Transitive relation

A relation R on a set A is transitive if whenever aRb and bRc, then aRc.

aRb ∧ bRc ⇒ aRc

Transitive closure

The transitive closure of R is the smallest transitive relation containing R. It adds pairs needed to make the relation transitive.

R⁺ = R ∪ R² ∪ R³ ∪ ⋯

Warshall’s algorithm

A matrix method that determines whether a path exists from vertex i to vertex j, allowing intermediate vertices one by one.

W[i,j] ← W[i,j] ∨ (W[i,k] ∧ W[k,j])

Meaning of the matrix entries

Represent the relation as a 0–1 matrix M: M[i,j] = 1 when the pair (i,j) is in the relation, and 0 otherwise. In each iteration k, check whether going from i to k and then k to j creates a path.

02 · Worked example

Step-by-step example

Let A = {1, 2, 3} and R = {(1, 2), (2, 3)}. Its adjacency matrix is:

M123
1010
2001
3000

Initial matrix W⁽⁰⁾

The direct edges are 1 → 2 and 2 → 3.

Allow vertex 1 as an intermediate (k = 1)

No new path is created through vertex 1, so the matrix stays the same.

Allow vertex 2 as an intermediate (k = 2)

Since 1 → 2 and 2 → 3, add the path 1 → 3. The entry W[1,3] becomes 1.

W[1,3] = W[1,3] ∨ (W[1,2] ∧ W[2,3]) = 0 ∨ (1 ∧ 1) = 1

Allow vertex 3 as an intermediate (k = 3)

No further entries change. The final transitive-closure matrix is:

W123
1011
2001
3000

Answer: R⁺ = {(1,2), (2,3), (1,3)}.

Summary

Remember

  • Write the relation as a 0–1 adjacency matrix.
  • Consider every vertex k as a possible intermediate vertex.
  • Update with W[i,j] = W[i,j] ∨ (W[i,k] ∧ W[k,j]).
  • The final matrix identifies all reachable pairs and gives the transitive closure.
  • For an n × n matrix, the algorithm runs in O(n³) time.
